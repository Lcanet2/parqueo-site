# it-desk-site

Page de présentation d'**IT Desk**, logiciel de helpdesk et de gestion de parc
auto-hébergé (ticketing, inventaire, catalogue de demandes, workflows visuels).

Publiée avec GitHub Pages : <https://lcanet2.github.io/it-desk-site/>

Une seule page statique, sans dépendance : les polices (Archivo, Inter,
IBM Plex Mono) sont inlinées en base64, aucune requête réseau n'est faite au
chargement. Thèmes clair et sombre suivant les préférences du système.

Le code de l'application vit dans un dépôt séparé.
